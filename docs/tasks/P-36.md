# P-36 Project card rebuild

Files: `client/modules/project/components/project-card.tsx`, `project-card-member.tsx`, `project-list.tsx`, `project-filters.tsx`, page `apps/web/src/app/(app)/(admin)/projects/page.tsx`.

## Problem

Name, `Archived` badge, avatar and the `⋯` menu are in one header row and fight for space; the Archived badge sits next to the title and pushes things around. Card reads as a pile of parts.

## Result

A clean, scannable card in a responsive grid (1 / 2 / 3 columns at <768 / <1280 / ≥1280 px). Whole card is one click target that opens the project's tickets (board filtered to this project).

Card structure:

1. **Top row**: project avatar (colored initials, existing `Avatar`) on the left; `⋯` menu on the right (Settings, Open SDK setup, Archive/Restore, Delete — destructive items separated and asking via `ConfirmDialog`). Menu click does not trigger card navigation.
2. **Title block**: project name (single line, truncate with tooltip), under it a muted slug/key line in monospace (`/checkout-web`).
3. **Stats row** (muted, small, with icons): open tickets count, total tickets count, last ticket "2 h ago" (or "No tickets yet"). Use data that already exists; if a count is not available from the project list query, extend that query.
4. **Footer row**: member avatar stack (max 4 + "+N") on the left; created date on the right in muted text.

### Archived state

No badge in the title row. Instead the whole card is visually de-emphasized (reduced contrast of avatar and text, grayscale avatar) and a slim status strip is shown at the **top edge of the card**: archive icon + "Archived", muted background. The menu shows Restore instead of Archive. Clicking the card still opens it. Archived projects sort after active ones and an "Active / Archived / All" segmented filter sits in `project-filters` (default Active).

### States

Loading: card skeletons matching the structure. Empty: existing empty state. Hover: border/elevation change only, no layout shift. Focus-visible ring on the card.

## Out of scope

Project settings sheet layout (P-35). New project create sheet.
