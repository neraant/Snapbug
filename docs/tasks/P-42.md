# P-42 MCP page: show the tools in the UI

Page: `apps/web/src/app/(app)/mcp/page.tsx`; module `client/modules/user-token` (or a new `client/modules/mcp`). Data comes from the catalog of P-41 through an endpoint (`mcp.listTools`), not from a hand-copied list.

## Goal

A user opens the page and understands in 30 seconds: what an agent can do with their token, how to connect, and which tools are available to them.

## Layout

Page header: "MCP" + description "Let AI agents work with your tickets." Tabs (underline): **Tools** (default) · **Connect** · **Tokens**. (Tokens tab replaces the MCP-token list in Settings; Settings keeps a link "Manage tokens →". Coordinate with P-37 so tokens exist in one place only.)

### Tools tab

- Summary line: "14 tools · 9 read · 5 write".
- Toolbar: search input, segmented filter All / Read / Write, group select.
- Tools grouped by area (Tickets, Comments, Projects, Members, Overview, Search, Activity) in a two-column responsive grid of compact cards, or a single list at <1024 px. Each card:
  - icon by area, tool name in monospace (`list_tickets`), a `Badge` **Read** (neutral) or **Write** (warning tone), and for admin-only tools an `Admin` badge;
  - one-sentence plain-language description ("Find tickets by status, severity or text");
  - a scope chip (P-43) when scopes exist.
- Click opens a right `Sheet` with: long description, **Inputs** table (name, type, required, description), **Returns** short text, **Example prompt** ("Show me the high severity tickets that are new") with a copy button, and a JSON example call in a `Code` block with copy.
- Tools the current user cannot use (admin-only for a member) are shown dimmed with a lock icon and tooltip "Requires an administrator".
- Empty search result: "No tools match".

### Connect tab

- Client selector (segmented): Cursor · Claude Desktop · Claude Code · Other. Each shows a ready config snippet in a `Code` block with Copy; the server URL is prefilled from the current origin; the token placeholder reads `YOUR_TOKEN`. Under it a numbered mini-list: 1 Create a token, 2 Paste the config, 3 Ask the agent to list your tickets.
- A "Test connection" is **not** required.

### Tokens tab

The list from P-26/P-37 (name, scopes chips, created, last used if available, revoke via `ConfirmDialog`) with **Create token**.

## States

Loading skeleton cards; error with Retry. EN + RU strings. No new colors beyond existing `Badge` variants.

## Out of scope

Defining which tools exist (P-41) and scope semantics (P-43).
