# P-31 "Copy this token" dialog

## Why

The dialog shown after creating an MCP user token (`client/modules/user-token/components/create-user-token-dialog.tsx`) looks raw. The same moment exists for project key rotation (`sdk-setup-rotate-api-key-dialog.tsx`) and invitation links. One polished component should serve all of them.

## Build

A shared `SecretRevealDialog` in `apps/web/src/client/modules/shared/` (design-system primitives only). Use it for: new MCP token, rotated project key. (Invitation copy link in P-34 may reuse the field part.)

## Layout (top to bottom)

1. Header: check/key icon in a soft circle, title "Token created" (or "New API key"), muted description "Copy it now. You won't be able to see it again."
2. Warning strip (`warning` tone, small, with icon): "Store this secret somewhere safe. If you lose it, create a new one." Not a giant alert.
3. Secret field: read-only monospace field, full width, value masked as `snbg_••••••••••••` by default with an eye toggle to reveal; a primary-style `Copy` button attached to the right inside the same control. After copy the button text/icon changes to "Copied" for 2 s (use `use-copy-text`). The secret can be selected and copied by hand too.
4. Optional metadata line under the field (muted): token name and "Created just now".
5. For MCP tokens only: a collapsible "How to use" snippet (the MCP client config JSON, in the `code.tsx` block with its own copy button). Collapsed by default.
6. Footer: single `Done` button on the right. The dialog is closed by Esc/Done only. Clicking outside does not close it. Closing before the secret was copied asks nothing, but the `Done` button label becomes "I've copied it" until the first copy happens, to nudge the action.

## Behaviour

- Secret is held only in component state while the dialog is open and is cleared on close.
- Copy works with the secret masked.
- The create-token form step (name input) stays a separate small dialog; submitting it swaps to this dialog in place (no flicker, no second overlay).
- Mobile: full width, field wraps without horizontal page scroll.

## Out of scope

Server behaviour of token/key creation.
