# P-44 Settings: appearance and personal preferences

Builds on P-37 (tabs + `SettingsSection` layout). Adds to the **Profile** tab and a new **Appearance** tab; adds no organization-level settings (those stay TBD under P-23).

## Tabs after this task

Profile · Appearance · Notifications (P-47) · Organization · Access tokens (or a link to the MCP page, see P-42).

## Profile tab

- Display name (editable, Save), email (read-only with muted "Used to sign in"), avatar initials preview, **Change password** row (current + new + confirm, uses existing auth rules) — reuse existing endpoints; if a missing endpoint is needed add it with a test.
- Interface language (existing, saves on change).
- Time zone select (default: browser time zone, "Detected: Europe/Berlin" hint). Used for all absolute timestamps in the app, activity sidebar and tickets.

## Appearance tab

All saved on change (quiet "Saved" check, no Save button), stored per user (database for cross-device; a cookie/localStorage mirror to avoid flash on load).

| Setting              | Control                                                                        | Notes                                                                        |
| -------------------- | ------------------------------------------------------------------------------ | ---------------------------------------------------------------------------- |
| Theme                | three visual option cards: **Light**, **Dark**, **System** with small previews | uses the existing theme provider; no flash on load                           |
| Accent color         | row of 6–8 color swatches (existing `ColorSwatchButton`)                       | applies to primary buttons, focus ring, links; check contrast in both themes |
| Density              | segmented: Comfortable · Compact                                               | changes row height/padding of tables and lists via a root data attribute     |
| Date format          | select: Relative ("2 h ago") · Absolute ("15 Nov 2026, 21:33")                 | affects tables, comments, activity                                           |
| 24-hour time         | switch                                                                         | shown only with absolute format                                              |
| Reduce motion        | switch (defaults to the OS setting)                                            | disables non-essential animation                                             |
| Default landing page | select: Overview · Tickets                                                     | where `/` redirects                                                          |
| Sidebar              | switch: Start collapsed                                                        | uses existing sidebar state util                                             |

A live **Preview** panel on the right (at ≥1024 px) shows a mini ticket row and a button in the chosen theme/accent/density, so changes are visible before leaving the tab.

## Details

- Defaults equal today's behavior, nothing visually changes for existing users.
- Add a header quick toggle for theme only if the user menu already has a place for it; otherwise skip.
- All strings EN + RU.

## Out of scope

Custom fonts, per-project themes, widget theme (exists in project settings).
