# P-40 Global search in the header: UI/UX

Files: `client/modules/global-search/components/global-search.tsx`, `hooks/use-global-search-shortcut.ts`, `consts/texts.const.ts`; the header lives in `client/modules/shared/ui/app-sidebar/components/app-sidebar-header.tsx` (or the app layout header). Behavior of P-19 (scope, project access) does not change.

## Problem

The search jumps: the field changes width and position on focus/typing, the result list shifts layout, results have no icons or hierarchy.

## Result

Pattern: PostHog / Sentry / Linear command-style search.

### Trigger (closed state)

- A fixed-width button that looks like an input: search icon, muted "Search tickets and projects…", and a `⌘K` / `Ctrl K` keycap on the right. Fixed width (about 280 px at ≥1024 px, icon-only button below 768 px). It never changes size or moves other header items, in any state.
- `⌘K` / `Ctrl+K` and `/` open it from anywhere (not while typing in an input).

### Open state

- Opens a **centered command dialog** (about 560 px wide, 15 % from the top, scrim behind), not an inline dropdown under the header. The header does not re-layout at all. Esc closes; focus returns to the trigger.
- Top: input with search icon and a clear button; a spinner replaces the icon while loading (same size, no jump).
- Results area has a **fixed height** (about 360 px, scrolls inside). No height animation; while loading keep previous results dimmed, or show 4 skeleton rows on first load. The dialog never resizes between states.
- Results grouped with muted group labels: **Tickets**, **Projects** (max 5 per group, "Show all in tickets →" link row when more).
- Ticket row: status icon (colored dot/icon by status), short id (`SB-42`, monospace muted), title (truncate), right side project name badge and severity icon. Project row: colored avatar initials, name, slug muted.
- The matched substring in titles is bold/highlighted.
- Keyboard: ↑/↓ moves the highlight (row highlight is the only selection state), Enter opens, `⌘Enter` opens in a new tab, Tab does not leave the dialog. Mouse hover moves the highlight too.
- Empty query: show "Recent" (last 5 opened tickets/projects, stored locally) or, if none, a hint row "Type to search tickets and projects".
- No results: "No results for “query”" plus a hint to check spelling; no layout jump.
- Footer bar (muted, small): `↑↓ navigate · ↵ open · esc close`.
- Debounce 200 ms; ignore stale responses (no flicker of old results replacing newer ones).

### Details

- All strings EN + RU. Icons from `lucide-react` only. Light and dark themes checked.
- Members never see results from projects they cannot access (unchanged).

## Out of scope

New searchable object types (members, comments).
